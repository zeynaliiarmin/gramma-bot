## ۶) موضوعات قابل توجه برای شما

1. **AvalAI**: اتصال از این سندباکس به `api.avalai.ir` time-out می‌شد (محدودیت شبکه‌ی محیط، نه مشکل کد). روی سرور شما کار خواهد کرد؛ تا آن زمان کپشن‌ها با fallback قالب‌محور تولید می‌شوند (هیچ چیزی کرش نمی‌کند).
2. **مینیاپ**: تا وقتی بک‌اند Docker روی دامنهٔ HTTPS عمومی بالا نیاید، مینی‌اپ روی Vercel به‌صورت «فرانت‌اند آماده» لایو است و بک‌اند هم از طریق Docker (پورت 8000) سرو می‌شود. متغیر `VITE_API_BASE` را (در Env پروژهٔ Vercel ساخته شد) با آدرس بک‌اند عمومی پر کنید تا dashboards واقعی را نشان دهد.
3. **Meta**: حالت `simulation` فعال است؛ برای اتصال واقعی پیج‌ها، طبق `docs/META_SETUP_FA.md` اپ متا بسازید و کاربران را طبق `docs/META_TESTERS_FA.md` (تا ۲۴ تستر) اضافه کنید.
4. برای **deploy خودکار** (هر push → دیپلوی خودکار): در Vercel، پروژهٔ `gramma-bot` را به ریپوی `zeynaliiarmin/gramma-bot` متصل کنید (دمی‌خاند دکمه Import Git Repository؛ تغییر مربوط به همان پروژهٔ جدید است). این کار را طبق قانون «در صورت شک از من بپرس» به‌صورت دستی انجام ندادم تا هیچ ریسکی به پروژه‌های دیگر نرسد.
